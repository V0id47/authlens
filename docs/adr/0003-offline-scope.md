# ADR 0003 — Offline scope and three deterministic rules

Accepted 2026-09-11. First delivery processes one authorized regular file with no network operations. SSH grammar and normalized JSONL are explicit; three explainable rules deliver a complete investigation flow. A SIEM, plugin runtime, blocking engine or GeoIP service would increase trust boundaries before validating core reasoning.

Sliding windows group by host/service/source and where needed user. Emit the earliest threshold crossing once per rule/group to bound repetitive alerts; later episode enumeration is intentionally absent and prominently documented. No baseline learning means predictable behavior but more false positives and missed slow/distributed patterns. Neither tradeoff can be hidden behind a severity score.
